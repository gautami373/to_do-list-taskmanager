Project Overview

TaskFlow is a simple web-based To-Do List and Task Manager developed using Python and Flask.

Objectives

  • Add and manage tasks.
  • View pending and completed tasks.
  • Mark tasks as completed.
  • Delete unwanted tasks.
  • Track task statistics.

Technologies Used

  • Python
  • Flask
  • HTML
  • CSS
  • Jinja2
